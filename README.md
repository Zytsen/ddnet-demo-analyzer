# DDNet Demo Analyzer

Drop a DDNet / Teeworlds 0.6 `.demo` file onto the page to analyse it: team run window, freezes and saves,
alive time, replay with follow camera, heatmaps, movement stats, events and exports.

## Credits
The demo parser (Huffman frequency table, snapshot/delta format, character physics used for dead reckoning)
is based on the open-source DDNet / Teeworlds code: https://github.com/ddnet/ddnet.
Please check and respect their license terms (see their `license.txt`).
